SICOSEP CENASE - CONTROL UNIFICADO DE REENTRENAMIENTO

1. Descomprime el archivo ZIP.
2. Reemplaza app.py y requirements.txt en la carpeta de tu aplicación Streamlit.
3. Si usas Streamlit Cloud, sube/confirma el cambio en GitHub y reinicia la app (Manage app -> Reboot).
4. Si se ejecuta en PC: pip install -r requirements.txt; streamlit run app.py
5. Carga los PDF nuevos y exporta Excel nuevo (no reutilices archivos Excel antiguos).

REGLA: una sola fecha de reentrenamiento, la MÁS RECIENTE que figure en la tabla Reentrenamientos del certificado SICOSEP, válida para ambos niveles. Próximo vencimiento: + 24 meses. Si no hay reentrenamiento, se utiliza fecha de registro de Nivel 2 + 24 meses.
